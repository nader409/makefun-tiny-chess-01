A compact 0x88 chess engine in under 4 KB of Python: negamax with alpha-beta pruning, a transposition table, quiescence search, killer moves and MVV-LVA ordering, searching to a fixed node budget so every game replays deterministically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
